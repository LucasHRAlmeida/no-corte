# No corte

A operação espacial da Starlink, em duas figuras. Código puro: um HTML, sem framework, sem build, sem coleta.

Não é um teto de pontos fixos. É uma casca fina, perto, que se move inteira — e que foi desenhada para cair.

Desenho geométrico. Terra esférica de 6 371 km. Não é peça da SpaceX.

## Worker

```sh
npx wrangler deploy
```

O Worker serve `public/index.html`. Nome: `no-corte`.
